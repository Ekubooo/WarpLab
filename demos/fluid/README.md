# Fluid demos

Current algorithms:

- `sph`: smoothed particle hydrodynamics using Warp's official example.
- [PBF2WayCoupling](PBF2WayCoupling/README.md): Warp PBF with Akinci particle boundaries, dynamic mesh rigid bodies, and two-way coupling.

Future algorithms such as LBM or APIC should use sibling directories.
