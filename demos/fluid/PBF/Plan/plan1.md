# 复杂场景底面与五面解析墙体的统一 SDF 烘焙方案

本文仅记录当前已讨论的做法，供后续修改代码时继续完善，不构成完整实施计划。本次只新增方案文档，不修改功能代码。

## 1. 目标与输入

烘焙一个统一 SDF，表示封闭流体容器的静态固体边界：复杂场景构成底面，四周与顶部由有厚度的解析墙体构成。

底面输入采用场景合成器的最终 Boolean 合成 mesh，即导入 OBJ 与程序化地形完成布尔合成后的结果。默认讨论具有长方形水平底座的场景。

## 2. 内嵌长方体与场景边缘对齐

内嵌长方体定义容器内部空间的水平范围与顶部位置：

- 两个水平方向的边界取自场景平整底座的长方形边界，完整覆盖底座的水平范围。
- 内嵌长方体的水平边缘与场景底座边缘严格重合，不添加公差、间隙或水平 padding。墙体内侧面贴合场景最外层阶梯的垂直外侧面。
- 竖直方向的容器高度由用户自定义，不采用场景 mesh 包围盒的高度。

参考图片中的“坐标轴墙体”用于说明水平贴合关系；图中的尺寸不作为本方案的固定参数，也不据此确定最终坐标轴约定。

## 3. 外嵌长方体与五面墙体

外嵌长方体的长、宽、高按同一比例比内嵌长方体增大，具体比例、数值及竖直定位方式待定。内外长方体之间的实体区域形成有体积的墙体。

普通的“外长方体减内长方体”会保留六个面，包括一个平整底面。为仅保留四周与顶面，采用以下构造：

1. 保留内嵌长方体确定的水平边界和顶部位置。
2. 将用于相减的内长方体向下延伸，使其穿过外长方体底部。
3. 从外长方体中减去这个向下延伸的内长方体，得到底部开口的五面实体墙壳。
4. 将五面墙壳与复杂场景实体求并集，由复杂场景提供容器底面。

向下延伸只用于去除墙壳自身的平整底面，不改变墙体内侧的水平对齐关系。墙体下端与场景底座必须形成连续封闭的连接，不能在底座边缘留下通向外部的缝隙；具体竖直范围后续确定。

墙厚由内外表面的实际间距决定。若水平居中，则侧墙厚度为相应水平尺寸差的一半；顶墙厚度取外顶面与内顶面的高度差，不能在尚未确定竖直定位时直接认定为高度差的一半。

## 4. 统一 SDF 的组合与烘焙做法

以“固体内部为负、外部为正”为符号约定。对同一个采样位置 `p`：

- `d_scene(p)`：查询最终 Boolean 场景 mesh 得到的有符号距离。
- `d_outer(p)`：外长方体的解析有符号距离。
- `d_inner_cut(p)`：向下延伸、用于相减的内长方体的解析有符号距离。

五面墙壳与最终边界的隐式布尔组合为：

```text
d_walls(p)    = max(d_outer(p), -d_inner_cut(p))
d_boundary(p) = min(d_scene(p), d_walls(p))
```

预处理时在统一采样网格上评估组合场，并烘焙为一个 SDF，供后续流体程序查询。解析墙体可以直接参与上述隐式组合，无需先生成墙体三角网格，再与场景进行网格 Boolean 操作。

上述 `min/max` 公式定义实体的布尔关系及零等值面；组合后不保证所有位置的数值都是严格的欧氏距离。是否需要距离重建及具体烘焙实现，留待后续讨论。

当前合成流程为：生成阶梯 → 导入并放置 OBJ → 阶梯实体求并集 → 与 OBJ 求并集 → 导出最终场景。合成器自行生成阶梯，不依赖先运行独立地形生成器。

资产路径均相对于 `boundary/`：输入模型位于 `Assets/origin/`，独立程序化地形位于 `Assets/procedural/`，合成场景位于 `Assets/output/`。当前默认的 `Assets/output/stairs_scene_bool.obj` 是本方案的底面 mesh 参考输入；`stairs_scene.obj` 是原始拼接对照，不能替代最终 Boolean 结果。独立地形输出也不能一律视为完成布尔合成的封闭实体。

坐标处理参考 `export_scene_mesh()`：当前场景内部使用 Z-up，默认导出为 Y-up，也可选择 Z-up。后续读取场景并构造解析墙体时，应以实际导出坐标为准，使两者处于同一坐标系；当前仅记录该参考，不确定新的轴转换或尺寸对齐方案。
