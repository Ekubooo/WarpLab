# PBF issues

优先级说明：P0＝阻断；P1＝高；P2＝中；P3＝最低，暂缓处理。

- [ ] [P3｜最低，暂缓] 同进程多实例的全局常量绑定问题（2026-10-20）
  - 触发条件：同一 Python 进程中，先创建并运行一个 `Example`，随后创建另一个实例；常见于自动化测试、批量参数实验、界面内重建或切换场景，以及同时运行多个仿真。
  - 问题：`GRID_id`、`SDF_id`、`VMAP_id` 和配置参数被绑定为模块全局编译期常量。后续实例重新赋值 Python 全局变量，不会自动替换已编译 kernel 中的常量，可能继续查询前一个实例的资源或沿用其配置。
  - 已验证：第二个实例可能查询第一个实例的网格，导致 lambda 错误；先开启负压钳制，再创建关闭钳制的实例，已编译 kernel 仍沿用开启状态。
  - 当前决定：优先级设为最低，暂不处理。当前“每次启动只运行一个固定配置的实例”的主流程可继续使用；`reset_simulation()` 复用原资源，不触发实例重建问题。
  - 后续处理时机与方向：明确需要上述同进程多实例或重建场景时，再考虑将资源句柄保留为实例 kernel 参数，或为不同实例和配置建立独立的 kernel 特化及编译生命周期。
